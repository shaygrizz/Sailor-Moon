# Moonveil — The First Star

Играбельный первый срез браузерной JRPG на **Godot 4.5.2 / GDScript / WebAssembly**. Оригинальный мир волшебных хранительниц, вдохновлённый классическими JRPG. Это основа проекта и короткая завершённая глава, **не готовая кампания на 20–40 часов**.

## Запуск

Готовая Web-сборка находится в `build/web`. Локальный адрес при запущенном сервере: **http://127.0.0.1:8060**.

Из PowerShell в папке проекта:

```powershell
# Запустить сервер для уже собранной игры
./tools/run.ps1 serve

# Нативный запуск, редактор Godot, проверки и новая Web-сборка
./tools/run.ps1 play
./tools/run.ps1 editor
./tools/run.ps1 test
./tools/run.ps1 export

# Встроенный инструмент для редактирования JSON-каталогов
./tools/run.ps1 content
```

Для этого компьютера Godot установлен в `%LOCALAPPDATA%/MoonveilTools`. На другом компьютере установите Godot 4.5.2, его Web export templates и Python 3; добавьте `godot` и `python` в PATH. Для редактирования достаточно открыть `project.godot` в Godot. Игра в браузере не требует установки Godot или Python у игрока.

Кроссплатформенные команды:

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/test_runner.gd
godot --headless --path . --export-release Web build/web/index.html
python tools/serve.py
```

Не открывайте `index.html` через `file://`: WebAssembly нужно обслуживать через HTTP. `build/` и `artifacts/` не хранятся в Git. Перед экспортом на другом компьютере создайте `build/web`.

## Что уже можно играть

- Две хранительницы: Селена и Ирис; две локации.
- Вступление, хранительница, закрытый ларец, ключ, переход через врата, бой, возвращение и завершение квеста.
- Движение, взаимодействие мышью/касанием; WASD/стрелки; E/пробел; левый стик/D-pad и A.
- Пошаговый бой с очередью скорости, маной, критическими ударами, уязвимостями, лечением, защитой, предметами и командной атакой.
- Опыт и уровни, награды, инвентарь, журнал квеста.
- Автосохранение, три ручных слота, резервная копия, проверка данных и миграция v1 → v2.
- Адаптивная раскладка, фокус кнопок для клавиатуры/геймпада, частицы, временная музыка исследования/боя и звук меню.
- Каталоги JSON, пакеты контента, редактор JSON, симулятор боя, монитор F3 и CI-проверки.

### Прохождение

Поговорите с хранительницей → откройте ларец справа → войдите во врата слева → победите стража → вернитесь в святилище → поговорите с хранительницей. Лунный луч силён против тени, Звездопад — против стража. Защита восстанавливает ману. Хранительница лечит отряд. После поражения можно повторить бой.

## Higgsfield и графика

Выполнена попытка генерации окружения через **Higgsfield**, модель `gpt_image_2_5`. Сервис отклонил запрос: **`Requires basic plan or higher.`** Job ID не выдан; изображения не получены. Точный запрос и статус сохранены в [docs/art-generation.json](docs/art-generation.json).

Текущие иллюстрации — временные SVG, созданные в проекте; музыка — оригинальные синтезированные заготовки. Они **не являются результатом Higgsfield**. После доступной генерации заменить пути в JSON можно без изменения боевой системы. Подробный порядок — [art direction](docs/design/ART_DIRECTION.md).

## Проверки и ограничения

- Godot headless: **341 проверка, 0 ошибок**; симулятор: **100/100 побед** при тестовой стратегии.
- Проверена вся глава через настоящие сервисы и Godot-сцену, включая повторную загрузку завершённого квеста.
- Chrome/WebGL2: проверены вход в игру, диалоги, путешествие, бой и выбор цели касанием, portrait 390×844, сохранение в IndexedDB и продолжение после перезагрузки; ошибок браузера нет. Снимки и отчёт лежат в `artifacts/`.
- Реальные iPhone, Android, физический геймпад и Safari пока не проверены. 60 FPS — целевая метрика, а не подтверждённая гарантия.
- Сохранения локальны для текущего устройства/браузера; облачного сервера пока нет.
- Публичного развёртывания нет: сервер слушает только `127.0.0.1`.
