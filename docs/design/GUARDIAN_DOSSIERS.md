# Досье хранительниц

Пользовательские карточки послужили ориентиром для отбора разделов: биография, характер, личные интересы и способности. Их текст не перенесён целиком. Досье интегрировано в прежнее анимированное меню: асимметричные плашки, персональный цвет, планетарный знак, пиксельный портрет и компактная типографика. Новых растровых иллюстраций для этой правки не генерировалось.

Тексты всех десяти профилей: `data/action/profiles.json`. Можно менять bio, traits, interest и role без изменения UI-кода; после редактирования нужна сборка. role описывает реализованное игровое поведение, а не полный список сил в манге. Биографии не раскрывают крупные сюжетные повороты. Свободные цитаты, возраст и неподтверждённые имена родителей опущены.

Справочная сверка: [Ами](https://www.wikimoon.org/index.php/Ami), [Рэй](https://wikimoon.org/index.php/Rei_Hino), [Макото](https://wikimoon.org/index.php/Makoto_Kino), [Минако](https://wikimoon.org/index.php/Minako_Aino). Это вторичные справочные источники; при дальнейшей детализации биографий нужно обращаться к выбранному изданию манги. Например, утверждения референса о школе Рэй и погибших обоих родителях не перенесены; имя матери Ами из игровой телеадаптации не выдаётся за манга-канон.
