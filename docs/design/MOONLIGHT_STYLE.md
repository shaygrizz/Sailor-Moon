# «Лунный свет»: визуальный стиль экшена

Единое направление для мира и интерфейса. Все цвета и общие помощники лежат в `scripts/action/style.gd`; меняйте их там, а не в местах вызова.

## Принципы

- **Сдержанность.** Один акцент (роза) на тёмном индиго, золото только тонкими линиями. Никаких сплошных цветных плашек.
- **Читаемость важнее декора.** Игрок, враги и опасности всегда светлее фона; замах врага — красное свечение, видное через любые слои.
- **Глубина слоями, как в Hollow Knight.** Дальний город движется медленно (0.28), улица — со скоростью камеры, тёмный передний план — быстрее (1.3).
- **Свет — аддитивный.** Всё, что светится (фонари, кристаллы, удары, алтарь, выход), рисуется в режиме `ADD` поверх мира.

## Палитра

| Токен | Цвет | Где |
|---|---|---|
| `INK` | `#0a0918` | затемнения, вуали, подложки |
| `PANEL` | индиго 88% | панели, диалог |
| `GOLD` | `#e8c98e` | заголовки-подписи, линии, фокус |
| `ROSE` | `#f3a8c8` | единственный акцент, приёмы |
| `CREAM` | `#fff5e6` | основной текст |
| `MIST` / `MUTED` | лаванда | второстепенный текст |
| `HEART` / `DANGER` | розовый / красный | здоровье / угроза |

## Типографика

- Заголовки и пункты меню: Cormorant Garamond (`serif`), без наклона.
- Подписи: системный шрифт с межбуквенным интервалом (`_caps`), только прописные, 11–13 px.
- Текст: системный шрифт 17–23 px, кремовый.

## Слои мира (`level.gd`)

1. `Parallax2D` с картиной улицы (вторая копия зеркальная, стык закрыт сакурой) и фонарями.
2. `terrain.gd`: мостовая с плющом, мраморные карнизы с золотой вставкой, бездна с туманом, кристаллы Тёмного королевства. Рисуется один раз.
3. Игрок, враги, снаряды; тени под ногами.
4. Аддитивный слой свечения.
5. `atmosphere.gd`: светлячки и лепестки, тёмный передний план, пост-обработка (виньетка, мягкое свечение, ночная цветокоррекция) на `CanvasLayer` 5, под интерфейсом.

## Интерфейс (`action_ui.gd`)

- HUD: круглый портрет с дугой энергии (насечки — одно лечение), сердца, задача справа, полоса босса внизу по центру.
- Меню: полумесяц как маркер фокуса, золотая линия под пунктом.
- Оверлеи: подпись, заголовок и тонкая линия; страница под ними скрывается.
- Диалог: окно как в визуальной новелле, мир остаётся виден, текст печатается.
