# Быстрая замена музыки

Закройте игру. Положите файлы в папку `Music` рядом с `SailorMoon.exe` и `SailorMoon.pck`, затем снова запустите игру. Пересборка не нужна. В редакторе используется папка Music в корне проекта.

Сейчас для меню, уровня, боя и победы назначен ваш `Music/music-puzzle3.mp3` с повтором. Чтобы быстро заменить фон везде, замените этот файл другим MP3 с тем же именем. Для разных мелодий по ситуациям измените соответствующие поля `external` в `Music/audio.json`; ниже приведены примеры отдельных имён.

| Файл | Назначение |
|---|---|
| menu.ogg | Главное меню |
| exploration.ogg | Уровень |
| battle.ogg | Босс |
| victory.ogg | Победа |
| menu_click.wav | Интерфейс |
| attack.wav | Удар |
| magic.wav | Магия |
| hurt.wav | Получение урона |

Если файла нет, звучит встроенный временный вариант.

## MP3, WAV, другие имена и громкость

Откройте `Music/audio.json` текстовым редактором. В нужной записи измените `external`, например на `Music/my_theme.mp3`. Поддерживаются OGG Vorbis, WAV и MP3. Переименование расширения не конвертирует файл. Пути отсчитываются от папки EXE; в JSON используйте `/`.

`loop: true` включает повтор. `gain_db: -9` уменьшает громкость на 9 дБ. Для эффектов обычно нужен `loop: false`. Поле `path` сохраняет резервный встроенный ресурс. Пример замены только музыки меню:

```json
{
  "tracks": {
    "menu": {
      "path": "res://assets/audio/music/exploration.wav",
      "external": "Music/my_theme.mp3",
      "loop": true,
      "gain_db": -6
    }
  }
}
```

Внешний JSON объединяет секции `tracks` и `sfx` по ключам; запись одного трека заменяется целиком. При синтаксической ошибке используются встроенные настройки. После редактирования перезапустите игру.

Общая громкость, музыка и эффекты регулируются в меню игры. Остальные параметры движка, включая длительность плавного перехода, находятся в `data/action/audio.json` и требуют пересборки. Не удаляйте PCK: он содержит ресурсы игры.
