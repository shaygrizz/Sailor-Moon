# Объём и план развития

## Выполнено — первый играбельный срез

Небольшая законченная глава, два персонажа, две локации, один состав боя, один последовательный сюжетный квест. Примерно 5–10 минут первого знакомства; длительность не измерялась пользовательским тестированием. Модульные доменные сервисы, базовая валидация, JSON-контент, пакетные модификации при сборке, local saves, тесты и Web-экспорт.

## Следующий этап: качество основы

- Получить доступный тариф Higgsfield и заменить временные иллюстрации: окружение, portraits/expressions, character atlas, enemies, magic effects.
- Проверить настоящие iPhone/Safari, Android/Chrome и геймпады; измерить время старта, FPS, память и draw calls.
- Перенести UI в отдельные сцены/компоненты, расширить доступность и вывести весь текст в локализацию.
- Атласы, анимации ходьбы/боя, TileMapLayer, коллизии, камера и переходы; async resource loading.
- Полная схема JSON, сообщения об ошибках по точному пути, импорт/экспорт сохранений, migration fixtures.

## Следующий этап: глубина RPG

| Требование из брифа | Текущее состояние | Что требуется |
|---|---|---|
| Статы, уровень, опыт, базовые навыки | Работают | Дальнейшая кривая роста и контент |
| Криты, уязвимости, защита, лечение, командная атака | Работают | Расширенная настройка AI и комбинаций |
| Buff/debuff, статусные эффекты | Не реализованы | Effect components, длительности/стэки, очередь событий |
| Экипировка, пассивы, talent tree | Зарезервированы поля | Item instances, stat pipeline, правила разблокировки и UI |
| Трансформации, костюмы, эмоции, связи, affinity | Зарезервировано частично | Механики, прогресс, портреты и анимации |
| Голоса, cinematic finishers, boss intro | Не реализованы | Контент и presentation pipeline |
| Города, школы, замки, Moon Kingdom, космос, секреты | Не реализованы | Сюжетный план, карты, NPC, враги, баланс |
| Мир и fast travel | Две связанные сцены | Глобальная карта, unlock rules, навигация |
| Побочные/ежедневные/relationship quests, achievements | Не реализованы | Обобщённая модель целей и устойчивые идентификаторы |
| Облачные сохранения | Только граница адаптера | Backend, auth, синхронизация, конфликтная политика |
| Погода, day/night, water reflections, bloom | Статичный фон и частицы | Отдельные системы с мобильным performance budget |
| Продвинутое адаптивное/пространственное аудио | Только смена двух музыкальных петель | Микшер, crossfade/layers, полноценный саундтрек |
| Визуальные quest/dialogue/NPC/item/map editors | Универсальный JSON editor | Специализированные редакторы/валидация/undo |
| Save editor, animation preview | Не реализованы | Отдельные dev tools |
| Runtime mods / пользовательские файлы | Только пакеты до сборки | Импорт, asset registry, совместимость и миграции |
| 20–40 часов, HD production art, 60 FPS на телефонах | Цели, не достигнутые свойства | Производство и проверка контента |

Каждый этап должен заканчиваться небольшой завершённой главой, профилированием на устройствах и проверкой совместимости сохранений. Создание большой кампании до проверки этих основ увеличит объём переделок.
