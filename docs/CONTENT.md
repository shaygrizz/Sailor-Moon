# Контент и расширение

## Файлы

- `data/manifest.json` — каталоги и упорядоченный список пакетов контента.
- `data/balancing/game.json` — стартовое состояние, движение, бой, рост уровня, ограничения, частицы/громкость.
- `data/characters/party.json`, `enemies.json` — акторы, статы, навыки, оформление.
- `data/skills/skills.json` — cost, power, kind, element, target.
- `data/items/items.json` — расходники и ключевые предметы.
- `data/maps/maps.json` — фон, точки взаимодействия, координаты [0..1].
- `data/events/interactions.json` — условия и команды NPC/объектов.
- `data/events/encounters.json` — состав противников и награды.
- `data/dialogues/story.json` — реплики на русском.
- `data/quests/quests.json` — шаги, темы событий, фильтры и награды.

## Новая точка взаимодействия

Добавьте точку в `points` карты:

```json
{"id":"observatory","name":"Обсерватория","icon":"✦","position":[0.6,0.7],"interaction":"observatory"}
```

Добавьте взаимодействие:

```json
"observatory": [
  {"when": [{"path": "flags.observed", "equals": true}],
   "commands": [{"type": "notice", "text": "Звёзды всё ещё сияют."}]},
  {"when": [], "commands": [
    {"type": "flag", "id": "observed", "value": true},
    {"type": "notice", "text": "Вы нашли новое созвездие."}
  ]}
]
```

Выполняется **первая** подходящая ветвь. Последняя ветвь без условий — fallback. Доступные команды: `dialogue`, `notice`, `restore_party`, `flag`, `item`, `event`, `battle`, `travel`. Для квестового события в конце диалога задайте `topic` у команды `dialogue`. Закрытие диалога до конца не отправляет событие.

## Навыки

Поддержанные `kind`: `damage`, `heal`, `guard`. Цели: `enemy`, `ally`, `self`, `all_enemies`. Новый числовой вариант существующего навыка добавляется только через JSON; новая механика эффекта требует расширения resolver. Поля `equipment`, `passives`, `talents`, `relationships` пока являются зарезервированными данными и **не реализуют механику сами по себе**.

## Пакеты контента

Создайте `mods/example.json`:

```json
{"catalogs":{"items":{"comet_fragment":{"name":"Осколок кометы","description":"Редкий трофей.","kind":"key","price":0}}}}
```

Добавьте `res://mods/example.json` в `manifest.mods`. Пакеты применяются по порядку; последний побеждает при совпадении ID. Запись переопределяет целую сущность, не отдельное поле. Каталог config через mods намеренно не перезаписывается. Web-версия упаковывает моды при экспорте; пользовательская загрузка внешних модов во время игры пока не реализована.

После правки: запустите тесты, затем экспорт. Переименование ID, уже попавших в сохранения, требует миграции.

## Content Studio

`./tools/run.ps1 content` открывает редактор каталогов с JSON-полем, нумерацией строк и проверкой перед записью. Это универсальный редактор, а не визуальные специализированные quest/map/animation editors. Он проверяет типы основных полей и ссылки; семантически странный баланс всё равно может пройти. Используйте симулятор и тестовую игру после изменений.

## Контроль размера и генераторы

SVG исходники и WAV-заготовки сохранены в `assets/`. `tools/create_content.py` и `extend_content.py` нужны только для восстановления стартового набора и **перезаписывают** данные. Не запускайте их в обычном build pipeline. Результат импортируется Godot; `.godot/` является кэшем и не коммитится.
