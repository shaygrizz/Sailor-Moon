# Архитектура Windows-прототипа

Точка входа: `scenes/action/main.tscn`; композиция модулей: `scripts/action/sailor_game.gd`. Старые scripts/core и пошаговые модули принадлежат предыдущему прототипу.

| Модуль scripts/action | Назначение |
|---|---|
| catalog.gd | Чтение и проверка JSON |
| player.gd | Физика, состояния, энергия и сигналы атак |
| level.gd | Геометрия, камера, попадания, контрольная точка и победа |
| enemy.gd | Враги, HP и замедление |
| projectile.gd | Поведение и визуальные эффекты магии |
| atlas.gd | Нарезка PNG на SpriteFrames |
| action_ui.gd / menu_button.gd | Меню, отряд, HUD и анимации |
| native_save.gd | Сохранения с временным файлом и резервной копией |
| music_director.gd | Внешние треки, встроенный резерв и плавные переходы |
| controls.gd | InputMap клавиатуры и геймпада |

В `data/action`: config.json — физика/баланс, characters.json — персонажи, skills.json — приёмы, levels.json — размещение, story.json — диалоги, audio.json — звук. Они упакованы в PCK и требуют экспорта после правок. Только внешняя музыка заменяется без экспорта. Фактические привязки управления задаёт controls.gd; bindings в config — справочное поле.

Новая способность: добавьте запись skills, назначьте её персонажу; для нового поведения расширьте projectile/level. Новые числа и подписи не требуют изменения логики. Строки атласов и индексы кадров заданы каталогами. Коллизия персонажа постоянна и не зависит от неровностей сгенерированных кадров.

Сохранения и настройки находятся в `%APPDATA%/SailorMoonAction`. Тесты используют отдельные подпапки. Сохраняются режим, персонаж, позиция, HP/энергия, предметы, контрольная точка и победа над боссом. Обычные враги при загрузке создаются заново.

`tools/run.ps1 test` проверяет физику, десять персонажей, состояния, магию, сохранения и сюжетные переходы. `tools/capture_action.gd` снимает настоящее OpenGL-окно: меню, отряд, игру, атаку сердцами и настройки. Автотесты не заменяют длительный плейтест и проверку на других видеокартах.

`tools/run.ps1 export` собирает Windows x64 EXE/PCK, музыку-конфигурацию, инструкции и лицензии. Для распространения нужен весь каталог build/windows.
