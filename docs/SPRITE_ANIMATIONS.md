# Расширенные анимации и чистая нарезка

Для каждой из десяти хранительниц подготовлен отдельный лист из 32 поз встроенным ChatGPT Images. Исходники: `assets/sprites/expanded`. Усаги использует `moon-transparent.png`, отдельную версию после запроса на удаление фона. Точные промпты: `docs/design/EXPANDED_SPRITES.json`.

| Состояние | Кадры | Частота |
|---|---|---|
| Ожидание | 0–3 | 4 FPS |
| Прыжок | 4–7 | 16 FPS |
| Бег | 8–15 | 18 FPS |
| Ближняя атака | 16–19 | 18 FPS |
| Магия | 20–23 | 12 FPS |
| Рывок | 24–25 | 16 FPS |
| Падение | 26–27 | 8 FPS |
| Урон | 28–29 | 10 FPS |
| Приземление | 30–31 | 16 FPS |

Управление остаётся отзывчивым: короткая анимация приземления не блокирует бег, прыжок или атаку. Привязка к ногам и размер холста постоянны внутри набора персонажа. Художественная согласованность сгенерированных поз всё ещё может требовать ручной доводки; число кадров само по себе не делает анимацию финальной.

## Почему исчезли соседние фрагменты

Раньше одинаковая сетка разрезала широкие позы вместе с волосами или оружием соседнего кадра. `tools/measure_sprite_frames.py` теперь анализирует связные силуэты в альфа-канале и сохраняет границы в `data/action/sprite_regions.json`. Он не перерисовывает PNG. Для пересекающихся прямоугольников сохраняются строки чужих пикселей; `atlas.gd` исключает их из отображаемой текстуры в памяти. Результат кэшируется, исходные файлы остаются нетронутыми.

При замене листа повторите измерение, импорт Godot и экспорт. Измеритель требует 32 отдельных силуэта и останавливается, если не может их сопоставить. Не используйте произвольный лист с другим порядком поз без изменения config.json.

## Стартовый экран

При каждом запуске игры показывается исходный общий постер. Просмотр досье не меняет стартовый постер; нажатие «Выбрать хранительницу» активирует индивидуальную иллюстрацию для этой сессии. Язык и выбранный игровой персонаж по-прежнему сохраняются. Новая сессия снова начинается с общего изображения.

Проверка: `tools/check_sprite_upgrade.gd` проверяет стартовый экран, явный выбор, число кадров и одинаковый размер холстов, а также снимает все 32 кадра каждой хранительницы и прыжок Усаги в реальном игровом окне.
