# Sailor Moon — In the Name of the Moon

Нативный прототип 2D action-platformer для Windows x64 на Godot 4.5.2. Графическое меню вдохновлено Persona. Иллюстрация, фон и спрайты созданы встроенным ChatGPT Images.

## Запуск

Запустите `build/windows/SailorMoon.exe`. Для переноса распакуйте весь `build/SailorMoon-Windows.zip`. Рядом с EXE должен оставаться `SailorMoon.pck`. Godot, Python и браузер игроку не нужны.

## Что реализовано

- Исходный общий постер при запуске; персональная иллюстрация включается после явного выбора героини.
- По 32 позы на каждую из десяти хранительниц, восемь фаз бега и отдельное приземление. Нарезка исключает соседние фрагменты. Подробности: `docs/SPRITE_ANIMATIONS.md`.

- Десять уникальных постеров: выбранная героиня появляется в меню, досье и загрузке.
- Русский, английский и итальянский языки в настройках, с сохранением выбора.
- Перенос и подгонка текста, плавная смена досье, иллюстрированные портреты без фрагментов соседних спрайтов. Подробности: `docs/PRESENTATION_AND_LANGUAGES.md`.

- Анимированные главное меню, загрузка и отряд; настройки звука, полный экран, пауза и сохранение.
- Короткий сюжетный пролог по событиям Act 1: Луна, Усаги, ёма в ювелирном магазине и спасение Нару.
- Тренировка за десять главных хранительниц с каноническими именами и разными магическими приёмами.
- Бег, регулируемая высота прыжка, двойной прыжок, скольжение и отскок от стены, рывок, серия ближних ударов, энергия и перезарядки.
- Тиара, сердца, туман, лёд, огонь, молния, цепь, волны, сфера и глефа.
- Кадры ожидания, бега, прыжка, падения, атаки и урона. Сгенерированные атласы ещё требуют ручной полировки; некоторые состояния используют общие кадры.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Движение | A/D, стрелки | Левый стик |
| Прыжок | Space / W / ↑ | A |
| Рывок | Shift | RB |
| Удар | J | X |
| Приём | K / Q | Y |
| Спецприём | L / E | LB |
| Отряд | Tab | Back |
| Пауза / назад | Esc | B |

В тренировке откройте отряд и нажмите «Выбрать». Для победы победите ёму и дойдите до правого края уровня. Поддержка геймпада реализована, физическим контроллером не проверялась.

## Разработка

```powershell
./tools/run.ps1 play
./tools/run.ps1 editor
./tools/run.ps1 test
./tools/run.ps1 export
```

Нужен Godot 4.5.2 и Windows export templates для сборки. Скрипт ищет Godot в `%LOCALAPPDATA%/MoonveilTools`, затем в PATH. Можно открыть `project.godot` напрямую.

- Замена музыки: `docs/MUSIC_QUICKSTART.md`.
- Модули и редактирование: `docs/ACTION_ARCHITECTURE.md`.
- Границы сюжета: `docs/MANGA_STORY.md`.
- Точные промпты изображений: `docs/design/CHATGPT_IMAGES.json`.

Текущий объём — один уровень и короткий пролог, не полная кампания по манге. Остальные акты, уникальные боссы и финальный саундтрек пока не реализованы. Музыка и звуки временные и заменяемые. Предыдущая браузерная JRPG сохранена как исторический прототип: `docs/legacy/README_BROWSER.md`.
